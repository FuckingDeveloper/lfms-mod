# Approved bounded banner declaration contract

Source factories MUST execute once after native built-in registration and before
source common setup. The target composition MUST install that boundary before
source listeners. Only attached declarations participate. A failed factory MUST
prevent completion, preserve its cause and declarations, and MUST NOT be retried
silently. Early source holder reads and late/duplicate registration MUST fail.

Source declaration object identity and hash-name metadata MUST be retained.
The target MUST create actual native BannerPattern values through native data
loading, using registry-key asset identity and the native translation convention.
The generated data pack MUST have low priority and MUST permit normal data-pack
overrides. It MUST NOT mutate frozen registries or fabricate RegisterEvent.
Source values MUST NOT impersonate loaded native registry holders. Source hash
lookup/old saved banner NBT and source pattern subclasses remain explicit gaps.

Source BannerPatternItem MUST become a native Item with the delayed native
PROVIDES_BANNER_PATTERNS component and LOOM_PATTERNS item-tag membership. Original
pattern-tag identity, item properties and description tooltip intent MUST survive.
Source pattern-item subclasses with changed callbacks require separate evidence.

This contract covers only the proven banner family. It MUST NOT silently apply
the changed factory phase to arbitrary source data-driven registries.
